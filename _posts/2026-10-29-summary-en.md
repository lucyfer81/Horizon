## [Apple unveils MacBook Pro with PROLED XDR touchscreen display and significant weight reduction.](https://www.apple.com/macbook-pro/proled-xdr-display/) ⭐️ 8.0/10

Apple has announced a new MacBook Pro featuring a PROLED XDR touchscreen display, marking the first time a Mac laptop includes a touchscreen. The new models also achieve a notable weight reduction, with the 14-inch model dropping from 3.5 lb to 3.0 lb and the 16-inch model from 4.7 lb to 4.0 lb. This announcement represents a major strategic shift for Apple, ending its long-standing resistance to touchscreen Macs and potentially reshaping user interaction with macOS. The significant weight reduction, enabled by the switch to OLED technology, also addresses a key ergonomic concern for professional users who prioritize portability. The PROLED XDR display utilizes tandem OLED technology, which allows for high peak brightness \(up to 2000 nits\) and true blacks without a traditional backlight, contributing to the weight savings. The weight reduction of approximately 15% is attributed not only to the OLED screen but also to other unspecified design changes, as the slight thickness reduction alone is insufficient to account for it.

**Background**: PROLED is Apple&\#x27;s branding for its OLED display technology, where each pixel emits its own light, eliminating the need for a separate backlight layer used in traditional LCD or mini-LED screens. XDR \(Extreme Dynamic Range\) is Apple&\#x27;s marketing term for displays that offer high contrast ratios, wide color gamuts, and high brightness levels, previously featured in its mini-LED displays. The introduction of a touchscreen MacBook Pro is a notable departure from Apple&\#x27;s historical stance, where touch interaction was reserved for iOS/iPadOS devices, arguing that macOS was optimized for indirect input via trackpad and mouse.

## [Apple&\#x27;s system git and utilities still trust compromised eMudhra root certificates, requiring manual patching.](https://emudhra.we-have-a-problem.com/apple.html) ⭐️ 7.0/10

A security vulnerability exists where Apple&\#x27;s system-provided git and other command-line utilities on macOS still trust the compromised eMudhra root certificates, which were revoked due to weak key generation. Apple&\#x27;s official guidance, documented in a support article, recommends users manually edit the system certificate chain to mitigate the risk. This poses a significant security risk as it could enable man-in-the-middle \(MITM\) attacks for any software relying on the system&\#x27;s certificate trust store, potentially compromising credentials and data. It highlights systemic issues in OS-level certificate management and undermines Apple&\#x27;s security-forward branding, especially since OS updates have been known to revert user-applied fixes. The issue affects not just git but a range of system utilities that rely on the OS-level trust store \(e.g., in \`/etc/ssl\`\). Apple&\#x27;s mitigation is a manual process that users must apply, and it has been reported that subsequent macOS updates can revert these manual changes, reintroducing the vulnerability.

hackernews · galadran · Oct 28, 11:03 · [Discussion](https://news.ycombinator.com/item?id=50271640)

**Background**: eMudhra is a licensed Certifying Authority in India that issues digital signature certificates. Root certificates are foundational to Public Key Infrastructure \(PKI\) and establish trust for secure connections \(like HTTPS\). When a root certificate is compromised or has weak keys, it must be removed from trust stores to prevent it from being used to fraudulently sign malicious certificates. On macOS, many command-line tools use the system&\#x27;s certificate trust store for verifying TLS/SSL connections.
