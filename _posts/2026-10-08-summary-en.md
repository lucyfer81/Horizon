## [Margaret Hamilton, pioneering software engineer who led Apollo flight software development, has died.](https://news.mit.edu/2026/margaret-hamilton-computing-pioneer-dies-1007) ⭐️ 8.0/10

Margaret Hamilton, the computer scientist who coined the term &\#x27;software engineer&\#x27; and led the team that developed the on-board flight software for NASA&\#x27;s Apollo missions, died on September 30, 2026, at the age of 90. The news was announced by the Massachusetts Institute of Technology \(MIT\), where she directed the Software Engineering Division at the Instrumentation Laboratory. Hamilton&\#x27;s work was foundational to the success of the Apollo moon landings, proving that reliable, real-time software was critical for human spaceflight. Her advocacy for &\#x27;software engineering&\#x27; as a disciplined practice elevated the status of software development and influenced engineering practices across safety-critical systems for decades. Hamilton&\#x27;s team at MIT developed the software for the Apollo Guidance Computer \(AGC\), which had extremely limited memory and processing power by today&\#x27;s standards. While widely celebrated for her leadership, some historical discussions note debates about the precise extent of her individual contributions versus the collective team effort.

**Background**: The Apollo Guidance Computer \(AGC\) was the first embedded computer used in a spacecraft, guiding the command and lunar modules. In the 1960s, software development was often an informal, ad-hoc process; Hamilton and her team introduced rigorous engineering principles, such as error detection and recovery, to create ultra-reliable flight software. The term &\#x27;software engineering&\#x27; was coined to give this critical work the same professional standing as hardware engineering.

## [PSP&\#x27;s God of War Game Statically Recompiled to Run in a Web Browser via WebAssembly](https://github.com/snuri00/psp-web-recomp) ⭐️ 7.0/10

A developer has successfully statically recompiled the PlayStation Portable \(PSP\) game &\#x27;God of War&\#x27; into WebAssembly, allowing it to run directly in a modern web browser. This is achieved by translating the game&\#x27;s original MIPS machine code into C++, compiling it to WebAssembly, and linking it with a minimal reimplementation of the PSP&\#x27;s OS and graphics layer that uses WebGL2 for rendering. This project demonstrates a novel technical approach for bringing complex, native console games to the web without a traditional emulator, potentially opening new avenues for game preservation and distribution. It also sparks a technical debate about the definition of emulation versus recompilation and showcases the expanding capabilities of WebAssembly beyond typical web applications. The project specifically targets the PSP version of God of War, which was noted for its impressive graphics that rivaled some PS2 titles. A key technical nuance is that while the project avoids a full dynamic emulator, it still implements an emulation stack for the PSP&\#x27;s hardware interfaces, leading to debate about whether this constitutes a form of emulation.

hackernews · sn001 · Oct 7, 11:27 · [Discussion](https://news.ycombinator.com/item?id=49991243)

**Background**: Static recompilation is a form of binary translation where a program&\#x27;s machine code is translated from one instruction set architecture \(like the PSP&\#x27;s MIPS\) to another \(like WebAssembly\) ahead of time, rather than during execution. The PlayStation Portable \(PSP\) is a handheld console from Sony that used a MIPS-based CPU and its own operating system. WebAssembly \(WASM\) is a low-level, portable binary instruction format designed as a compilation target for high-level languages, enabling near-native performance within web browsers and other environments.
