vLLM v0.29.0 has been released, making Model Runner V2 \(MRV2\) the default execution core for all models. The release also introduces support for new models like Tencent&\#x27;s 770B Mixture-of-Experts \(MoE\) and includes numerous performance enhancements, such as CUDA graph memory profiling for KV cache auto-sizing and batch-sharded sampling to reduce memory usage. This release is significant as MRV2&\#x27;s new modular architecture promises higher throughput and efficiency for LLM inference, which is critical for scaling production deployments. The addition of support for massive models like a 770B MoE ensures vLLM remains a leading choice for serving the latest and most complex open-source LLMs. MRV2 now includes CUDA graph memory profiling to automatically size the KV cache and batch-sharded sampling that cuts per-step logits memory by a factor of the tensor parallelism degree \(1/TP\). The release also removes several deprecated model architectures and migrates others to the Transformers backend, constituting breaking changes.

github · khluu · Sep 9, 08:54

**Background**: vLLM is a high-throughput and memory-efficient inference and serving engine for large language models \(LLMs\). Model Runner V2 \(MRV2\) is a ground-up re-implementation of vLLM&\#x27;s core execution engine, designed to be more modular and efficient than its predecessor \(V1\), with benchmarks showing significant throughput improvements. The KV \(Key-Value\) cache is a memory structure used during LLM inference to store previously computed attention keys and values, speeding up generation for subsequent tokens; efficient management of this cache is crucial for performance.
